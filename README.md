# 🏢 واجهة موقع شركة رَص (RASS)

تصميم وبرمجة صفحة هبوط (Landing Page) تفاعلية لشركة رَص لتنظيم الفعاليات والمؤتمرات. 

## ✨ المميزات
- تصميم عصري وجذاب.
- واجهة مستخدم (UI) سلسة ومتوافقة مع مختلف الشاشات.

## 💻 التقنيات المستخدمة
- HTML
- CSS
- JavaScript
